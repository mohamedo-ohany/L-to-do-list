# 📝 To-Do List App

A clean, minimal, and responsive to-do list application built with vanilla JavaScript. Manage your tasks efficiently with local storage persistence.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

---

## ✨ Features

- ✅ **Add Tasks** — Quickly add new tasks with a simple input field
- ✅ **Mark Complete** — Toggle tasks between complete and incomplete
- ✅ **Delete Tasks** — Remove completed tasks you no longer need
- ✅ **Persistent Storage** — Tasks are saved to localStorage and persist across sessions
- ✅ **Responsive Design** — Works seamlessly on desktop, tablet, and mobile devices
- ✅ **Clean UI** — Modern, minimalist interface with smooth hover effects

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/mohamedo-ohany/L-to-do-list.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd L-to-do-list
   ```

3. **Open in browser**
   - Simply double-click `index.html`, or
   - Use a live server extension in VS Code

## 💻 Usage

| Action | How to |
|--------|--------|
| **Add a task** | Type in the input field and click "Add" |
| **Complete a task** | Click the checkbox next to the task |
| **Delete a task** | Click the "Delete" button (appears on completed tasks) |
